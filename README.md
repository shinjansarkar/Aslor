# Aslor ☀️

A modern and responsive solar-energy website designed to showcase solar solutions, services, and sustainable energy solutions through a clean and engaging user interface.

## 🌐 Live Demo

**[Visit Aslor](https://aslor.vercel.app/)**

## ✨ Features

* Modern and responsive design
* Clean solar-energy focused UI
* Smooth animations and interactive elements
* Mobile, tablet, and desktop responsive
* Service and solution sections
* Modern navigation and user experience
* Optimized frontend architecture
* Deployed on Vercel

## 🛠️ Tech Stack

* **React.js** – Frontend library
* **Vite** – Fast development and build tooling
* **Tailwind CSS** – Utility-first styling
* **JavaScript** – Application logic
* **Framer Motion** – Animations and transitions
* **Lucide React** – Icons
* **Vercel** – Deployment

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/shinjansarkar/Aslor.git
```

Navigate to the project:

```bash
cd Aslor
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## 🏗️ Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
